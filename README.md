# スーパー動画再生早丸君

動画の再生速度を操作する Chrome 拡張（Manifest V3）。
**外部通信なし。設定は利用者のPCの中だけに保存されます。**

最大の特徴は **「プレイリスト単位で除外できること」**。
基本 1.8 倍で見ているが音楽のプレイリストだけ等倍にしたい、という使い方のために作りました。
一度登録すれば、そのプレイリストを再生している間はずっと除外されます。

## インストール手順

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を **ON**
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`video-speed-controller`）を選ぶ
5. 動画のあるページを **再読み込み** してから使う

コードを書き換えたときは、拡張一覧のこの拡張にある更新ボタン（⟳）を押し、
対象ページを再読み込みしてください。

### 最初にやること

**「Global Speed」など他の速度制御拡張は無効化してください。**
両方が再生速度を書き換えて奪い合うため、正常に動きません。

## 使い方

### ツールバーのアイコンをクリック

```
┌──────────────────────────────┐
│ ⏻  早丸君             1.80x  │  ← 右が今の速度
├──────────────────────────────┤
│  0.25   0.50   0.75          │
│  0.90   1.00   1.10          │  クリックで即適用
│  1.25   1.50   1.80          │
│  2.00   3.00   16.00         │
├──────────────────────────────┤
│  0.25  0.5  1  2  4  8  16   │
│  ──────────●──────────────   │  スライダー（対数目盛り）
├──────────────────────────────┤
│  «    ‹   1.80   ›    »      │  «» ±0.5   ‹› ±0.1
├──────────────────────────────┤
│ この速度を適用する範囲         │
│  全体（既定）          1.80x  │
│  このサイト            未設定  │
│  このプレイリスト      未設定  │
│  この動画だけ          未設定  │
├──────────────────────────────┤
│ プレイリストの除外             │
│  ☑「音楽」を除外する           │
│     除外中の再生速度 [1.00] x  │
├──────────────────────────────┤
│ 除外中のプレイリスト  (2件)    │
│  音楽                  1.00x × │
│  作業用BGM             1.00x × │
└──────────────────────────────┘
```

左上の **⏻** で拡張全体を一時停止できます（サイト純正の速度メニューに戻したい時に使用）。

### キーボード

| キー | 動作 |
|------|------|
| D | 速度 +0.25 倍 |
| S | 速度 -0.25 倍 |
| R | 速度を 1.0 倍にリセット |
| Z | 10 秒戻す |
| X | 10 秒進める |

- キー操作は **「今そのページに効いている設定」** を書き換えます。
  たとえば全体の既定が効いているページで D を押すと、全体の既定が上がります。
  除外プレイリストを見ている時に D を押すと、その除外リストの速度が上がります
- 入力欄（input / textarea / select / 編集可能領域）にフォーカスがある間は無効
- Ctrl / Alt / Windows キーとの同時押しでは反応しません
- 日本語入力の変換中は反応しません
- 操作すると画面左上に約1.5秒だけ表示されます（全画面表示中も出ます）

## プレイリストの除外

### やり方

1. 除外したいプレイリストを再生する
2. 拡張のアイコンをクリック
3. 「〇〇を除外する」にチェック **← これで終わり**

以降そのプレイリストを再生している間は、指定した速度（既定 1.00 倍）になります。
他の動画は今まで通りの速度です。

### 仕組み

YouTube はプレイリストから再生すると URL がこの形になります。

```
https://www.youtube.com/watch?v=ISf883zt8fY&list=PLKEPxFnPwoDj_ImC-DAZgXvqMUfFqvpbo&index=362
                                             ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
```

この `list=` の値で判定します。プレイリスト内で次の動画へ自動で進んでも `list=` は
残るので、1本ごとの操作は不要です。

- 通常のプレイリスト … `PL…`
- 後で見る … `WL`
- 高く評価した動画 … `LL`
- ミックスリスト … `RD…`

すべて同じ仕組みで扱えます。

### `list=` が付かない開き方への対策

検索結果や通知からその動画を直接開くと、URL に `list=` が付きません。
そのままでは「音楽リストの曲だ」と判別できないため、2つの補助を入れてあります。

1. **学習** … 除外リストを再生している間、流れた動画IDを記録します。
   次にその動画を単体で開いても除外扱いになります
2. **一括登録** … 除外にチェックを入れた瞬間、再生画面のプレイリスト一覧から
   動画IDをまとめて記録します

**一括登録で全部は取れません。** 画面に読み込まれている分（数十件程度）だけです。
362件のような長いリストは、再生するたびに学習で少しずつ埋まっていきます。
記憶した件数は除外リストの各行に表示されます。

一括登録は YouTube の画面構造を読んでいるため、将来の YouTube 更新で
機能しなくなる可能性があります。その場合も `list=` による判定と学習は動き続けます。

## 速度の決定ルール

上にあるものが優先されます。

| 順位 | 条件 | 例 |
|---|---|---|
| 1 | この動画の個別設定 | 特定の1本だけ 1.0 倍 |
| 2 | 除外プレイリストに該当 | 音楽リスト → 1.00 倍 |
| 3 | プレイリストの個別設定 | 講義リスト → 1.2 倍 |
| 4 | サイトの個別設定 | amazon.co.jp → 1.5 倍 |
| 5 | 全体の既定 | 1.8 倍 |

ポップアップの「この速度を適用する範囲」で、どこに書き込むかを選びます。
各行の **×** でその設定を解除できます（解除すると1つ下の順位が効きます）。

---

## 注意

- **4.0 倍を超えると音声が出ません。** ブラウザの仕様で、0.5〜4.0 の範囲外は
  映像だけが無音で進みます。プリセットの `16.00` は無音早送り用です
- **D / S / R / Z / X の単押しを全サイトで奪います。** サイト独自のショートカットと
  衝突する場合は下記「キーの変更」で割り当てを変えてください
- **この拡張が速度の主導権を持ちます。** YouTube 純正の速度メニューで変更しても
  拡張の設定値へ引き戻されます。純正メニューを使いたい時は ⏻ で一時停止してください
- 拡張の一覧に「すべてのウェブサイトのデータの読み取り」警告が出ます。
  全サイトで動く仕様上、避けられません
- iframe 内の動画にも対応しています（`all_frames: true`）

## 権限について

| 権限 | 用途 |
|---|---|
| `storage` | 設定の保存（このPC内のみ。同期なし） |
| `activeTab` | アイコンを押した時だけ、そのタブのURLを読む（プレイリストIDの取得） |

`activeTab` はクリックした瞬間だけ有効で、権限の警告は出ません。
ネットワーク通信のコードは1行も含まれていません。

## 変更方法

### 数値の調整

`content.js` の先頭。

```js
const MIN_RATE = 0.25;   // 最低倍率
const MAX_RATE = 16.0;   // 最高倍率
const KEY_STEP = 0.25;   // D / S の増減幅
const SEEK_SEC = 10;     // Z / X のシーク秒数
const OSD_MS   = 1500;   // 画面表示が消えるまでのミリ秒
```

`MIN_RATE` / `MAX_RATE` を変えた場合は `popup.js` の同名の定数も合わせてください
（スライダーの目盛り計算に使っています）。

### キーの変更

`content.js` の `onKeyDown` 内、2か所を直します。

```js
if (key !== 'd' && key !== 's' && key !== 'r' && key !== 'z' && key !== 'x') return;
...
if (key === 'd') writeRate(effectiveRate + KEY_STEP);
```

例: D → A に変えるなら、両方の `'d'` を `'a'` にします。
キー名は `e.key` の小文字表記です（矢印キーなら `'arrowright'` など）。

### プリセットの数値

`popup.js` の先頭。

```js
const PRESETS = [0.25, 0.5, 0.75, 0.9, 1.0, 1.1, 1.25, 1.5, 1.8, 2.0, 3.0, 16.0];
```

3列で並ぶので、12個・15個など3の倍数にすると見た目が揃います。

### ±ボタンの幅

`popup.html` の `data-delta` を書き換えます。

```html
<button class="step" data-delta="-0.5">&laquo;</button>
```

### 特定のサイトだけで動かす

`manifest.json` の `matches` を書き換えます。

```json
"matches": ["https://www.youtube.com/*", "https://*.nicovideo.jp/*"]
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張の設計図 |
| `content.js` | ページ側の本体。速度適用・キー操作・URL監視・画面表示 |
| `background.js` | アイコンのバッジに現在の倍率を出すだけ |
| `popup.html` | ポップアップの構造 |
| `popup.css` | ポップアップの見た目（ダークモード対応） |
| `popup.js` | ポップアップの動作 |
| `icons/` | アイコン画像（16 / 32 / 48 / 128 px の PNG） |
| `LICENSE` | MIT ライセンス |
| `PRIVACY.md` | プライバシーポリシー |
| `docs/` | GitHub Pages で公開しているプライバシーポリシー（動作には無関係） |
| `promo/` | ストア用スクリーンショットの生成ページ（動作には無関係） |
| `STORE.md` | ストア提出用のメモ（動作には無関係） |
| `README.md` | このファイル |

ポップアップとページ側は **メッセージをやり取りしていません**。
ポップアップが `chrome.storage.local` に書き、ページ側が `storage.onChanged` で
それを受け取って即座に反映する、という一方向の流れです。

## アンインストール

`chrome://extensions` でこの拡張を削除してください。保存した設定も一緒に消えます。
レジストリやフォルダ外への書き込みは一切していません。
